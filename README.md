## Sobre o projeto
Interface do sistema interno de gestão da Don Energy (empresa de energia solar),
desenvolvida como Projeto Integrado da disciplina. Esta entrega cobre a
estruturação inicial da aplicação React e a implementação visual das telas de
Login, Dashboard e Clientes, a partir do protótipo desenvolvido no Figma.

## Tecnologias utilizadas
- React 19 + TypeScript
- Vite
- Tailwind CSS 4

## Como rodar localmente

```bash
npm install
npm run dev
```

A aplicação abre em `http://localhost:5173`.
